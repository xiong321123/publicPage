我还要感谢我的客户以及媒体和市场研究方面的同事。

2006 年我进入这个行业时，我认为营销人员是研究消费者欲望的权威，他们用理性的论据说服人们购买东西。

但是，我的客户（其中许多人供职于财富 500 强品牌）帮助我换位思考，他们接受了新的神经科学见解，并将其应用到他们的商业活动中。这些消费者神经科学的先驱是我学习消费者行为的伙伴。随着时间的推移，我发现自己和整个行业的思维都发生了巨大转变。这种转变是从强调权威的广告形式转变为强调真实性的广告形式；从理性转变为感性；从试图说服转变为试图吸引。这就是我们从消费者神经科学中学到的东西。消费者希望自由选择最适合自己的产品。他们不想被操纵。

要达到这一点，我们需要承担风险，并愿意检验曾经激进的观念，即神经科学可以加深我们对消费者的理解。我衷心感谢那些勇于深入研究的市场和媒体研究人员。
